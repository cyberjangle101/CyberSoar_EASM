# Security Policy

## Supported Versions

Only the latest release (see the [Releases page](https://github.com/cyberjangle101/cybersour-attack-surface-scanner/releases)) receives security fixes. Fixes ship as a new release, which installed agents offer to install from *System health → Updates*; container deployments update by deploying the new image tag.

## Reporting a Vulnerability

Please report vulnerabilities privately, not through public issues:

- Use GitHub's **Report a vulnerability** button on the repository's Security tab (private vulnerability reporting), or
- Email **jason12345@duck.com**.

Please include steps to reproduce and the affected version or commit. Reports will be acknowledged and addressed promptly.
